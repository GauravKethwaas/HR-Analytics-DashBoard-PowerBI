HR-Analytics-DashBoard-PowerBI
📊 Project Overview This project is a Power BI dashboard created to analyze employee attrition trends.   It provides insights into why employees leave jobs, based on demographics, job roles, salary slabs, and satisfaction metrics.

🛠 Tools & Technologies
- Microsoft Power BI
- Data Modeling (HR_Analytics dataset)
- DAX Measures
- Data Visualization (Bar, Donut, Line, Table)

🔑 Key Insights
- Total Employees: 1.42K  
- Attrition Count: 229  
- Attrition Rate: 16.2%  
- Avg Age: 37 years  
- Avg Salary: 6.5K  
- Avg Years at Company: 7  

Attrition Breakdown
- By Age → Highest in 26–35 group (111 employees)  
- By Gender → Male: 136, Female: 76  
- By Education → Life Sciences (38%), Medical (25%), Marketing (15%)  
- By Salary Slab → Majority attrition in Up to 5k slab (158 employees)  
- By Job Role → Laboratory Technicians (60), Sales Executives (55), Research Scientists (44)  

🎯 Purpose
This dashboard demonstrates HR data analytics skills including:
- Attrition analysis  
- Workforce demographics study  
- Salary slab vs attrition correlation  
- Visualization storytelling  

📈 Business Impact
Helps HR teams identify:
- Which age groups and roles have higher attrition  
- Salary ranges where employees are more likely to leave  
- Education fields contributing to turnover  
- Gender and department‑wise attrition trends
